# Graphing Linear Equations

## Overview

A **linear equation** in two variables produces a straight line when graphed. The most useful form for graphing is slope-intercept form $y = mx + b$, where you can read off the $y$-intercept and slope directly. Standard form $Ax + By = C$ is often used in systems, but you can always convert it to slope-intercept form to graph.

## Key Idea

In slope-intercept form:

$$y = mx + b$$

$m$ is the slope (rise over run) and $b$ is the $y$-intercept — the point where the line crosses the $y$-axis. To graph: plot $(0, b)$, then use the slope to locate a second point, then draw the line through both points.

## Worked Examples

**Example 1: Graph $y = 2x - 3$**

The $y$-intercept is $b = -3$, so plot the point $(0, -3)$. The slope is $m = 2 = \frac{2}{1}$, meaning for every 1 unit you move right, you move 2 units up. Starting from $(0, -3)$, move right 1 and up 2 to get the second point $(1, -1)$. Draw the line through $(0, -3)$ and $(1, -1)$.

Check: plug in $x = 2$: $y = 2(2) - 3 = 1$, so $(2, 1)$ should also be on the line. ✓

---

**Example 2: Graph $3x + 2y = 6$ using intercepts**

To graph standard form efficiently, find both intercepts. Set $x = 0$: $2y = 6$, so $y = 3$ — the $y$-intercept is $(0, 3)$. Set $y = 0$: $3x = 6$, so $x = 2$ — the $x$-intercept is $(2, 0)$. Plot both points and draw the line through them.

These two points are enough to define a unique line, which is why the intercept method works so cleanly for standard form.

---

**Example 3: Convert $y = -\frac{1}{2}x + 4$ to standard form**

Multiply every term by 2 to clear the fraction: $2y = -x + 8$. Then move the $x$ term to the left: $x + 2y = 8$. The coefficient of $x$ is positive, which is the conventional orientation for standard form.

Check: substitute the $y$-intercept $(0, 4)$: $0 + 2(4) = 8$ ✓

## Common Mistakes

- **Plotting slope as run over rise.** Slope is $\frac{\text{rise}}{\text{run}}$, not the other way around. If $m = \frac{3}{4}$, go up 3 and right 4 — not right 3 and up 4.
- **Confusing $x$-intercept with $y$-intercept.** The $y$-intercept is where $x = 0$ (on the vertical axis). The $x$-intercept is where $y = 0$ (on the horizontal axis).
- **Misreading negative slope direction.** If $m = -2$, you move down 2 for each unit right — or equivalently, up 2 for each unit left. Both give the same line.

## Quick Check

Try these before using hints:

1. What is the slope and $y$-intercept of $y = -3x + 5$?
2. Find both intercepts of $2x + 5y = 10$.
3. Does the point $(3, 1)$ lie on the line $y = -x + 4$?

*(Answers: slope $= -3$, $y$-intercept $= 5$; $(5,0)$ and $(0,2)$; yes, since $-3+4=1$)*
