# Adding Fractions (Like Denominators)

## Overview

When two fractions share the **same denominator**, you add them by adding the numerators and keeping the denominator unchanged. This works because both fractions are already cut into the same-size pieces — you are simply counting how many pieces you have in total.

## Key Idea

$$\frac{a}{c} + \frac{b}{c} = \frac{a + b}{c}$$

Think of the denominator as a label for the size of each piece. If you have 2 sevenths and 3 sevenths, you have 5 sevenths — the piece size (7) never changes, only the count does. Always simplify the result if possible.

## Worked Examples

**Example 1: $\frac{2}{7} + \frac{3}{7}$**

Both fractions are measured in sevenths, so the pieces are the same size. You are simply counting: 2 pieces plus 3 pieces gives 5 pieces. The piece size stays 7:

$$\frac{2}{7} + \frac{3}{7} = \frac{2 + 3}{7} = \frac{5}{7}$$

GCF(5, 7) = 1, so $\frac{5}{7}$ is already in simplest form.

---

**Example 2: $\frac{3}{8} + \frac{5}{8}$**

Again the denominator is the same (eighths), so add only the numerators: $3 + 5 = 8$.

$$\frac{3}{8} + \frac{5}{8} = \frac{8}{8}$$

Any fraction with the same numerator and denominator equals 1, because you have all the pieces that make up one whole. So $\frac{8}{8} = 1$.

---

**Example 3: $\frac{4}{9} + \frac{7}{9}$**

Add the numerators: $4 + 7 = 11$. The denominator stays 9.

$$\frac{4}{9} + \frac{7}{9} = \frac{11}{9}$$

The numerator (11) is larger than the denominator (9), which means the result is greater than 1. This is a valid **improper fraction**. Written as a mixed number: $11 \div 9 = 1$ remainder $2$, so $\frac{11}{9} = 1\frac{2}{9}$.

## Common Mistakes

- **Adding the denominators.** The denominator is not part of the count — it describes the piece size, which does not change when you combine pieces. $\frac{2}{7} + \frac{3}{7}$ is never $\frac{5}{14}$.
- **Forgetting to simplify.** After adding, always check whether the result reduces. For example, $\frac{3}{8} + \frac{3}{8} = \frac{6}{8}$, and GCF(6, 8) = 2, so the simplified answer is $\frac{3}{4}$.
- **Treating improper fractions as errors.** A result like $\frac{11}{9}$ is perfectly correct — it just means the sum is greater than one whole.
