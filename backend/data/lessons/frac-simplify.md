# Simplifying Fractions

## Overview

A **fraction** $a/b$ is in simplest form when the numerator and denominator share no common factor other than 1. You simplify by dividing both parts by their greatest common factor (GCF). The GCF is the largest whole number that divides evenly into both the numerator and denominator.

## Key Idea

Find GCF$(a, b)$, then divide both top and bottom by it:

$$\frac{a}{b} = \frac{a \div \text{GCF}}{b \div \text{GCF}}$$

Simplifying never changes the value of the fraction — it only changes how it looks. Dividing the numerator and denominator by the same number is equivalent to dividing by 1, which leaves the value unchanged.

## Worked Examples

**Example 1: Simplify $\frac{12}{18}$**

First, find GCF(12, 18). List factors of each: factors of 12 are 1, 2, 3, 4, 6, 12; factors of 18 are 1, 2, 3, 6, 9, 18. The largest factor they share is 6, so GCF = 6.

Because 6 divides evenly into both 12 and 18, you can cancel it from both parts without changing the fraction's value:

$$\frac{12}{18} = \frac{12 \div 6}{18 \div 6} = \frac{2}{3}$$

Check: GCF(2, 3) = 1, so $\frac{2}{3}$ is fully simplified.

---

**Example 2: Simplify $\frac{24}{36}$**

Find GCF(24, 36). Both are divisible by 2, 3, 4, 6, and 12. The greatest of these is 12, so GCF = 12.

Dividing both parts by 12 removes all shared structure at once, giving the simplest form directly:

$$\frac{24}{36} = \frac{24 \div 12}{36 \div 12} = \frac{2}{3}$$

If you had only divided by 6 (a common factor, but not the GCF), you would get $\frac{4}{6}$, which still shares a factor of 2 — not fully simplified yet.

---

**Example 3: Simplify $\frac{45}{60}$**

Find GCF(45, 60). Factors of 45: 1, 3, 5, 9, 15, 45. Factors of 60: 1, 2, 3, 4, 5, 6, 10, 12, 15, 20, 30, 60. The largest shared factor is 15.

Dividing both by 15:

$$\frac{45}{60} = \frac{45 \div 15}{60 \div 15} = \frac{3}{4}$$

Since GCF(3, 4) = 1, the fraction is fully simplified.

## Common Mistakes

- **Dividing only the numerator or only the denominator.** You must apply the same operation to both parts. Dividing just one part changes the fraction's value entirely.
- **Stopping too early.** If you divide by a factor that is not the GCF, the result is still not fully simplified. For example, dividing $\frac{24}{36}$ by 6 gives $\frac{4}{6}$, which still needs another step. Always verify GCF of your result is 1.
- **Assuming a fraction with small numbers is already simplified.** Check: GCF(4, 6) = 2, so $\frac{4}{6}$ is not simplified — it reduces to $\frac{2}{3}$.
